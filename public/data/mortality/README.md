# Cohort mortality tables

These six files are derived from the local copy of the Destatis cohort life tables for Germany, birth years 1926–2026. There is one CSV for each combination of sex (`male` or `female`) and mortality scenario (`low`, `medium`, or `high`), named `cohort_table_1926_2026_<sex>_<scenario>.csv`. The scenarios correspond to the source variants V1 (niedrig), V2 (mittel), and V3 (hoch), respectively. Refer to the [Destatis cohort life tables](https://www.destatis.de/DE/Themen/Gesellschaft-Umwelt/Bevoelkerung/Sterbefaelle-Lebenserwartung/kohortensterbetafeln.html) for their interpretation and underlying assumptions.

Each row describes one birth cohort. The first column is `birth_year`; the remaining columns `age_0` through `age_99` contain annual death probabilities. For example, `age_65` is the probability of dying before age 66 conditional on reaching age 65. Values are decimal fractions, not percentages. The original decimal digits are preserved, with decimal commas changed to decimal points; no fitting or rounding is performed.

The source also has an open-ended `100 und mehr` row with value 1 for each cohort. It is not an annual probability at age 100 and is excluded, as in the research project's mortality reader. These tables therefore do not describe mortality beyond age 100. A mixture of male and female tables, fitting a model, and application integration are future work.

## Provenance and regeneration

`manifest.json` records each original source filename, its SHA-256 checksum, the corresponding output checksum, and the variant mapping. It identifies the exact local source snapshot without implying a download or publication date. The source data themselves remain in the separate research project.

The conversion script defaults to the sibling research folder. From the website root, run:

```sh
npm run data:prepare
npm run data:check
```

To use a different copy of the six original source CSVs, append `-- --source-dir /path/to/kohortensterbetafeln_1926_2026` to either command. Preparation creates missing outputs and refuses to overwrite files that differ. The check compares all generated bytes and the manifest against the source without writing. The script verifies the source layout, variant, range, completeness, and terminal rows before producing the tables.

Source: Statistisches Bundesamt (Destatis), cohort life tables for Germany, birth years 1926–2026; data transformed as described above. Destatis describes its open-data terms at its [Open Data service page](https://www.destatis.de/EN/Service/OpenData/api-webservice.html), including the [Data licence Germany – attribution – version 2.0](https://www.govdata.de/dl-de/by-2-0). Check any dataset-specific terms before publication.
